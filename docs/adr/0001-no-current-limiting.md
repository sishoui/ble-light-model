# 不做电流限流与满功率解锁

## 状态

accepted

## 背景与决定

8×100 颗 WS2812B 全白理论电流约 48 A，通常的 LED 控制器会做电流估算、默认压到 50%、并要求显式「解锁」到 100%。

本项目**不做**这一层：固件不估算电流、不设 50% 上限、没有解锁命令。输出亮度只由每个灯效自带的 `b`（0–255）决定。产品负责人明确选择「不考虑电流电压」。

## 考虑过的替代

- 帧级电流估算 + 50% 默认上限 + 长按解锁（原 #4 旧地图方案）。
- 固定全局上限但不可解锁。
- 保留解锁交互、仅去掉具体电源参数。

## 后果

- 协议与 UI 更简单：没有 `SET_POWER_LIMIT`、没有「解锁」状态机、没有全局亮度层。
- 硬件安全不再由固件兜底：电源与线材不足时，高亮长亮可能过热或掉压。这是用户显式接受的取舍。
- 若将来要加回限流，属于新增能力（新命令 / 新参数），不改已有灯效语义；参见 `docs/spec/effects.md` §9、§10。
